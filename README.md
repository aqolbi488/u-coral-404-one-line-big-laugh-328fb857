A tiny TypeScript program that writes one funny line — a joke about an inheritance that turns out to be more than the heir bargained for — to `/output/entry.txt`, for make.fun's "One Line, Big Laugh" bounty. The line is a constant in `main.ts`, so every run produces the same deterministic output.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (Node runs the TypeScript directly). The program creates `/output` if needed and writes the single line to `/output/entry.txt`.
